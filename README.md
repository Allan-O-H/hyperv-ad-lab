# Hyper-V AD Lab

Windows Server AD lab on Hyper-V: build docs plus PowerShell scripts for provisioning, user management, and Entra ID reporting.

## Purpose

A self-built environment for practicing the day-to-day work of a systems administrator: standing up a domain, joining clients, and automating repetitive tasks with PowerShell. Everything here is reproducible from the docs.

## Lab Environment

**Host:** Lenovo X1, 32 Gb RAM, Windows 11 Pro with Hyper-V enabled
